# goEnumCVE
![alt text](https://raw.githubusercontent.com/snowpeacock/goEnumCVE/refs/heads/main/screenshot.png)

Using remote registry to enumerate windows version and Update Build Revision to find common CVEs. Re-implementation of netexec enum_cve.
No admin privileges needed.
## Usage
```
goEnumCVE.exe <file>
```
Where \<file\> contains a list of hosts.
